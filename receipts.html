Steps

    • Paid in Full branch (12 contacts) — Product Is Clients On Demand - Paid in Full →

        const payment = inputData.amount

output = { payment: paymentFormatted }
      2. Update contact field (action name: “Update contact field”) · Action type: Update field data · Field: COD Contract Price = {{payment.currency_symbol}}{{custom_code.2.output.payment}} → END
    • Split Pay branch (9 contacts) — Product Is Clients On Demand - Two Monthly Payments →
      1. Custom Code — Premium action (action name: “Split Pay & Format Currency”) · Language: Javascript · Property: amount = {{payment.total_amount}} · Code: 
        const payment = inputData.amount
const paymentFormatted = payment.toLocaleString();
const total = payment*2;
const totalFormatted = total.toLocaleString();
output = { total: totalFormatted, payment: paymentFormatted }
      2. Update contact field (action name: “Update contact field”) · Action type: Update field data · Field: COD Contract Price = {{payment.currency_symbol}}{{custom_code.1.output.total}} (full contract value = instalment × 2) → END
    • None branch (4 contacts) — When none of the conditions are met → END
